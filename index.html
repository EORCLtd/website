Understanding uncertainty
Defining uncertainty

Most decisions have to be made before the future is revealed.

Uncertainty is a state of having unknown information about the future. It prevents decision-maker from knowing the consequences of a decision but also comes with great value if managed properly.

EORC uses scenarios to represent the unknown information to identify the hidden value in uncertainty.

Why it matters

Significant value is hidden in uncertainty.

Managing uncertainty via scenario modelling help to make the optimal decision considering the expectation of the unknown future. This helps the decision to be more robust than decision made considering only one future. This also helps to find and quantify the value of flexibility.
